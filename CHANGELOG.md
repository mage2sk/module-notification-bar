# Changelog

All notable changes to this extension are documented here. The format
is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.21] - 2026-10-06

### Changed
- The close button has a 4px corner radius instead of 6px and a 44px wide tap area that fills the bar height on every screen size; on Luma the global 8px button radius no longer applies to it. From 769px up the bar text keeps 48px of space on each side so it never runs under the button.
